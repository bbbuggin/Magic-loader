Quick guide

How Magic Loader works on iPad.

  1. Choose a Bedrock .mcpack or .mcaddon file.
  2. Tap Share to Minecraft when available.
  3. Wait for Minecraft to import it.
  4. Activate it in the world's Resource Packs settings.
Magic Loader does not inject code into Minecraft or force unsupported shaders. It transfers pack files using iPadOS sharing.
